======相对燃速表======{{ zh:media::burnratiochart.png?30%&link}}该表显示数据库中所有发射药的相对燃烧特性。此类表格的排序并无标准。不同发射药制造商或经销商发布的表格往往差别很大，取决于各自的偏好。最常用的排序方式是**渐增性**。因此，该表允许按照不同因素进行不同的排序，您可以通过表格上方的按钮进行选择。**重要提示**相对燃速表仅用于在不同制造商之间进行粗略对比。该表并不能说明某种发射药在膛压特性方面的实际活度高低！表中列在同一位置的两种发射药，并不意味着其中一种就是另一种特定发射药的 1:1 替代品！这只表示它可能适合类似的应用。====排序方式=======渐增性===按发射药的渐增性系数 **//Bp//** 对表格排序。渐增性系数及其公式为 GRT 特有，计算方式如下：<code>Bp = sqrt( (2 * (k - 1)) * pow(Ba * phi(z1) * Qex,2) ) / 10000;</code>===猛度===按发射药的（初始）爆炸系数 **//Br//** 对表格排序。爆炸系数及其公式为 GRT 特有，计算方式如下：<code>Br = sqrt( (2 * (k - 1)) * pow(Ba * Qex,2) ) / 10000;</code>===猛度与渐增性（组合） ===使用发射药的猛度与渐增性组合系数 **//Brp//** 对表格排序。组合系数及其公式为 GRT 特有，是两个单一系数的//第二绝对矩//((平方平均值))：<code>Bp = sqrt( ( pow(Br,2) + pow(Bp,2) ) / 2 );</code>通过组合这两个系数，应能更实际地近似反映不同发射药的行为。
