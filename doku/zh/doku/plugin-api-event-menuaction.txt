======Event_MenuAction======点击插件的菜单项时，此事件会发送给插件。此事件无法关闭。===取值=====  * **//(integer) windowhandle//** - 当前 GRT 主窗口的窗口句柄  * **//(string) id//** - 被点击菜单项的 ID  * **//(string) label//** - 被点击菜单项的菜单文本  * **//(boolean) checked//** - 菜单项带勾选标记（true）或不带（false）===JSON 源（示例）===<code>{  "Event_MenuAction":{    "windowhandle":531876,    "id":"com.grt.plugin.tester.menu.version",    "label":"Version",    "checked":false  }}</code>
