======口径数据库======
{{ zh:media::dbcaliber.png?40%&link}}
口径数据库是所有口径及其相应规格的档案库，这些规格由官方机构（如 CIP）发布。GRT 安装后自带一套默认数据，用户可以对其进行扩展或编辑。

该数据库有两个主窗口和一个搜索表单：

  * 选择/查看口径
  * 搜索表单："全文搜索"
  * 口径列表

===选择/查看口径===
这是所选口径枪弹的自动生成图纸（插图），包含所有相关尺寸。

===搜索表单===
可用于在口径数据库中搜索任意文本。通配符："*" 代表任意多个字符，"?" 代表单个字符。

=====口径列表=====
  * **数据表**\\ 此图标代表该口径的数据表。本地存在时，点击即可打开。如果本地未找到数据表，则会自动从官方网站下载。 

  * **名称**\\ 该口径的正式名称（由 CIP 等官方标准化机构确定）

  * **机构**\\ 该口径的官方标准化机构

  * **类型**\\ 口径类型："rimmed"（有底缘）、"rimless"（无底缘）、"rimfire"（边缘发火）、"magnum"（马格努姆）、"pistol / revolver"（手枪/转轮手枪）或 "shotshell"（霰弹） 

  * **来源**\\ 口径的原产国

  * **日期**\\ 规格发布日期 

  * **修订**\\ 发布信息的修订版本

  * **更改**\\ 数据在本地数据库中被修改（更改）的日期。

==用户文件==
{{zh:media::caliber-database-userfile.png}}

由用户修改或新建的文件会以颜色标记。
它们同时会备份到系统的用户目录中。
启动较新版本的 GRT 时，这些数据会被自动导入/恢复。

这些文件是普通 XML 文件，包含由用户修改或新建的数据记录。

根据系统的不同，这些文件位于以下目录：
  * **Windows:**\\ //"C:\Users\<your user name>\AppData\Roaming\GordonsReloadingTool\"//
  * **Linux:**\\ //"home/<your user name>/GordonsReloadingTool/"//

=====从当前装药文件调用=====
{{ zh:media::dbcaliberload-call.png?30%&link}}
如果您不是点击工具栏中的工具图标，而是通过装药中的按钮访问口径数据库，还可以将选中的口径应用到当前装药。

**双击即可选中该口径，并将其全部数据应用到装药文件。 

此外，窗口中还会出现用于传输到装药文件的按钮：**

**[ 应用到装药数据 ]**\\
所选口径的全部数据会被应用到装药文件，效果如同双击列表条目。

{{ zh:media::dbcaliberload.png?30%&link}}
**[ 应用到装药数据（选择数值） ]**\\
点击此按钮会显示"选择要应用的数值..."对话框及列表。可以通过复选框选择需要传输到装药文件的数值。

"取消"按钮会在不应用数据的情况下关闭口径选择对话框。

=====右键菜单=====
右键单击口径可使用以下功能：

  * **新建** - 新建（本地）口径条目
  * **复制新建** - 以所选口径为基础新建（本地）口径条目
  * **编辑** - 编辑口径的任意数值 
  * **删除** - 从（本地）数据库中删除所选口径。系统会弹出对话框请求确认，确认删除选"OK"，否则选"Cancel"。
