======弹头数据库======
{{ zh:media::projectile-database.png?40%&link}}

这是所有可用弹头（bullets）的档案库，这些弹头由制造商和手工装填者贡献给本项目。安装时会安装最新版本的数据，之后可以编辑或扩展。 

弹头数据库主窗口包含菜单栏、搜索对话框和两个垂直排列的列表区域：

  * "文件"菜单
  * 表单："全文搜索"
  * 弹头列表 - 选择/查看弹头
  * 属性


=== 文件菜单 ===
此菜单提供与在**弹头列表**中右键单击相同的功能（新建、复制新建、导出、编辑、删除 - 见下文）。 

此外，还提供以下功能：

  * 保存更改 - 对数据库做出尚未保存的更改后，此项才可用。选择后，对数据库的所有更改都将被保存。
  * 导出 - 将弹头数据导出为 GRT 格式的 XML 文件

===全文搜索===
可用于在弹头数据库中搜索任意文本。通配符："*" 代表任意多个字符，"?" 代表单个字符。

=====弹头列表=====
这里列出所有可用弹头，按其制造商名称排序。点击某个制造商，会展开该制造商提供的所有弹头直径。再点击某个具体直径可进一步展开，查看该制造商指定的弹头/产品名称以及以下信息

  * **制造商**\\ 制造商名称

  * **产品名称**\\ 弹头的产品名称/制造商型号

  * ∅ **口径**\\ 弹头适用口径的直径（英寸）

  * ∅ **mm**\\ 弹头直径（毫米）

  * **格令**\\ 弹头重量（格令）

  * **UBCS**\\ 弹头的[[zh:doku:ubcs|UBCS 代码]]

  * **装药/批号**\\ 所做测量的批号/ID

  * **创建**\\ 数据集创建/更新到数据库的日期 

  * **修改**\\ 执行修改的作者名称（若有手动编辑或更改，将显示 grtuser）

==用户文件==
{{zh:media::projectile-database-userfile.png}}

由用户修改或新建的文件会以颜色标记。
它们同时会备份到系统的用户目录中。
启动较新版本的 GRT 时，这些数据会被自动导入/恢复。

这些文件是普通 XML 文件，包含由用户修改或新建的数据记录。

根据系统的不同，这些文件位于以下目录：
  * **Windows:**\\ //"C:\Users\<your user name>\AppData\Roaming\GordonsReloadingTool\"//
  * **Linux:**\\ //"home/<your user name>/GordonsReloadingTool/"//


===== =====
点击"取消"按钮，取消弹头选择。

点击"应用到装药数据"按钮，相关数值会被传回仿真主窗口。 

点击"应用到装药数据（选择数值）"按钮，可以选择要传回仿真主窗口的数值。 

===== 右键菜单 =====
右键单击条目会在上下文菜单中提供以下功能：


  * 新建 - 新建（本地）弹头条目
  * 复制新建 - 以所选弹头为基础新建（本地）弹头条目 
  * 导出 - 将所选弹头数据导出为 GRT 格式的 XML 文件
  * 编辑 - 编辑弹头的任意数值 
  * 删除 - 从（本地）数据库中删除所选弹头。系统会弹出对话框请求确认，确认删除选"OK"，否则选"Cancel"。
