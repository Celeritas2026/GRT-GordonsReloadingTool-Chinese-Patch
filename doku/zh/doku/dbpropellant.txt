======发射药数据库======
{{ zh:media::propellant-database.png?40%&link}}

发射药数据库是 GRT 中所有可用发射药的档案库。
发射药数据可以扩展和修改。

发射药数据库主窗口包含菜单栏、搜索对话框和两个
水平排列的区域：

  * "文件"菜单
  * 表单："搜索"
  * 属性（含发射药猛度图与详细信息）
  * 发射药列表 查看/编辑

=== 文件菜单 ===
此菜单提供与在**发射药列表**窗口中右键单击相同的所有功能
（新建、复制新建、导出、编辑、删除 - 见下文）。
此外，还提供以下功能：

  * 保存更改 - 对数据库做出尚未保存的更改后，此项才可用。选择后，对数据库的所有更改都将被保存。
  * 导入 - 从 GRT 格式的 XML 文件导入发射药数据
  
===搜索表单===
可用于在发射药数据库中搜索任意文本。通配符："*" 
代表任意多个字符，"?" 代表单个字符。

===活度图/发射药模型数据===
{{ zh:media::propellant-vivacity1.png?25%&link}}
**仿真计算中发射药的燃烧特性**由所谓的形状函数确定。
GRT 为此实现了一种三段式表示。这三段在活度图中以不同颜色显示。
其基础是发射药制造商提供的关于相应发射药燃烧特性
与活度的实测数据。

**如果有密闭爆发器**（测压弹）测量数据，
则会额外显示一条该测量的虚线单色图线。

**注意，**这只是可视化展示，并非可用于数学计算的图表。
出于许可方面的原因，图形化的发射药图表不用于推导精确测量值，
例如密闭爆发器测量数据。测压弹测量值（虚线）
仅以示意方式包含在内。

**另请参阅：** [[zh:doku:formalism|形式理论、数据来源与发射药模型]]

=====发射药列表=====
这里列出所有可用发射药，按其制造商
名称排序。点击某个制造商，会展开该制造商
的所有发射药，按各自的产品牌号/名称排序，并在各列中显示以下
信息： 

  * **//制造商//** - 制造商名称

  * **//产品名称//** - 发射药的商品名/牌号

  * **//数据状态//** - 记录的新旧程度，应尽可能新。

  * **//校准//** - 发射药模型开发/校准过程所用数据基础的颜色进度条。\\ //发射药模型是基于（测压弹）测量和弹道数据以数学方式建立的。随后会依据新的弹道数据对模型持续进行校准。弹道数据越多，模型就越准确。//\\ {{zh:media::propellant-database-colorbar.png}}
    * <color lightred>[ 红色 ]</color> = 数据基础急需您实际装药的实测数据来校准发射药模型，
    * <color darkyellow>[ 黄色 ]</color> = 数据基础还需要更多您的实际装药测量数据，
    * <color lightgreen>[ 绿色 ]</color> = 数据基础及模型表现良好到非常好

  * **//修改//** - 最后一次用户修改的名称与日期

==用户文件==
{{zh:media::propellant-database-userfile.png}}

由用户修改或新建的文件会以颜色标记。
它们同时会备份到系统的用户目录中。
启动较新版本的 GRT 时，这些数据会被自动导入/恢复。

这些文件是普通 XML 文件，包含由用户修改或新建的数据记录。

根据系统的不同，这些文件位于以下目录：
  * **Windows:**\\ //"C:\Users\<your user name>\AppData\Roaming\GordonsReloadingTool\"//
  * **Linux:**\\ //"home/<your user name>/GordonsReloadingTool/"//

===== =====

点击"取消"或"关闭"按钮，取消发射药选择并关闭数据库。
点击"OK"按钮，相关数值会被传回仿真主窗口。 
右键单击发射药可使用以下功能：


  * 新建 - 新建（本地）发射药条目
  * 复制新建 - 以所选口径为基础新建（本地）发射药条目
  * 导出 - 将所选发射药数据导出为 GRT 格式的 XML 文件
  * 编辑 - 编辑发射药的任意数值 
  * 删除 - 从（本地）数据库中删除所选发射药。系统会弹出对话框请求确认，确认删除选"OK"，否则选"Cancel"。
