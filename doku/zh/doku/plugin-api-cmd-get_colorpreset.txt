======Get_ColorPreset======
读取配色方案。

===参数===
  * //ColorPresetId// - 配色方案的 ID，输入 -1 可请求当前设置的配色方案。


====JSON 源码====

===命令===
<code>
{
  "Get_ColorPreset":{
    "ColorPresetId":-1
  }
}
</code>
