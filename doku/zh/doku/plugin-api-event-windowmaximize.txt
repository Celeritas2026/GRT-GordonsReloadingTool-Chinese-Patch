======Event_WindowMaximize======GRT 主窗口最大化后，此事件会发送给插件。可在插件清单中启用/停用此事件。===取值===  * **//(integer) windowhandle//** - 当前 GRT 主窗口的窗口句柄  * **//(integer) left//** - 窗口在屏幕上的左侧位置  * **//(integer) top//** - 窗口在屏幕上的顶部位置  * **//(integer) width//** - 窗口宽度  * **//(integer) height//** - 窗口高度===JSON 源（示例）===<code>{  "Event_WindowMaximize":{    "windowhandle":531876,    "left":944,    "top":108,    "width":1871,    "height":1118  }}</code>
