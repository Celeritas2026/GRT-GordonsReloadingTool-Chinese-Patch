======Get_TabResults======
读取标签页的仿真结果。

该函数提供一个用于传输的 ChunkStream，
数据即从该流中读取。

**参见：** [[zh:doku:plugin-api-cmd-get_chunk|Get_Chunk]] - 读取数据流的一部分

===参数===
  * //tabhandle// - 请求其仿真结果的标签页句柄。


====JSON 源码====

===命令===
<code>
{
  "Get_TabResults":{
    "tabhandle":132273211
  }
}
</code>
