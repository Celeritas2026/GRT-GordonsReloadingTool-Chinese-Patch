======Get_Chunk======
读取数据流的一部分。

部分函数会提供用于传输大量数据的 ChunkStream。
使用此函数可以按任意顺序读取数据包。
数据包数量 //n// 可通过 ChunkStream 的句柄获得。

===参数===
  * //chunkStreamHandle// - ChunkStream 的句柄。
  * //chunkIndex// - 数据包的索引，范围从 //0// 到 //n-1//。


====JSON 源码====

===命令===
<code>
{
  "Get_Chunk":{
    "chunkStreamHandle":"7835152",
    "chunkIndex":"0"
  }
}
</code>
