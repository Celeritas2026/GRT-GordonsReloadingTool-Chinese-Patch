Heading 1      ^ Heading 2       ^ Heading 3          ^  | Row 1 Col 1    | Row 1 Col 2     | Row 1 Col 3        |  | Row 2 Col 1    | some colspan (note the double pipe) ||  | Row 3 Col 1    | Row 3 Col 2     | Row 3 Col 3        |要让单元格水平合并，只需将其下一个单元格完全留空（如上所示）。请务必始终保持单元格分隔符的数量一致！===纵向标题===也可以使用纵向标题。|              ^ Heading 1            ^ Heading 2          ^^ Heading 3    | Row 1 Col 2          | Row 1 Col 3        |^ Heading 4    | no colspan this time |                    |^ Heading 5    | Row 2 Col 2          | Row 2 Col 3        |可以看到，决定单元格格式的是单元格前面的分隔符：==源码：==  | vertically | Row 1 Col 3        || Row 2 Col 1    | :::                        | Row 2 Col 3        || Row 3 Col 1    | :::                        | Row 2 Col 3        |除跨行语法外，这些单元格中不应包含任何其他内容。==源码：==  ^ Heading 1      ^ Heading 2                  ^ Heading 3          ^  | Row 1 Col 1    | this cell spans vertically | Row 1 Col 3        |  | Row 2 Col 1    | :::                        | Row 2 Col 3        |  | Row 3 Col 1    | :::                        | Row 2 Col 3        |===列对齐===表格内容也可以设置对齐。只需在文字相对的一端添加至少两个空格：在左侧添加两个空格为右对齐，在右侧添加两个空格为左对齐，两端至少各添加两个空格则为居中。^           Table with alignment           ^^^|         right|    center    |left          ||left          | 嵌入代码 =====您可以使用 "%%<code>%%" 标签将原始源代码嵌入文档中。==示例：==<code>#include <iostream>using namespace std;int main(){    int n, t1 = 0, t2 = 1, nextTerm = 0;    cout << "Enter the number of terms: ";    cin >> n;    cout << "Fibonacci Series: ";    for (int i = 1; i <= n; ++i){        // Prints the first two terms.        if(i == 1){            cout << " " << t1;            continue;        }        if(i == 2){            cout << t2 << " ";            continue;        }        nextTerm = t1 + t2;        t1 = t2;        t2 = nextTerm;        cout << nextTerm << " ";    }    return 0;}</code>==== 可下载的代码块 ====当您像上面那样使用 "%%<code>%%" 语法时，可能还希望让所展示的代码也可以下载。为此，您可以在语言代码后面指定一个文件名，如下所示：<code fibonacci.cpp>#include <iostream>using namespace std;int main(){    int n,
